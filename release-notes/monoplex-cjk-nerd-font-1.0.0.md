# Monoplex CJK Nerd Font 1.0.0

첫 공개입니다.

**Monoplex CJK**에 Nerd Fonts 3.5.1의 글리프를 더한 판입니다. 한글·한자·
가나에 Powerline 구분자와 파일 아이콘까지 한 글꼴에 들어 있습니다.

8종 굵기와 각각의 이탤릭이 들어 있습니다.

## 어떤 글꼴인가

- **KS X 1001의 한자 4,888자를 빠짐없이** 담았습니다. 한국어 문서에
  한자가 섞여도 칸이 어긋나지 않습니다
- 히라가나·가타카나·반각 가타카나가 있어 일본어도 그대로 나옵니다
- Powerline, Material Design Icons, Codicons, Devicons, Font Awesome 등
  Nerd Fonts 3.5.1의 글리프가 들어 있습니다

한글·한자·가나는 라틴의 정확히 두 배 폭이고, 아이콘은 라틴과 같은 폭입니다.
무엇을 섞어 써도 칸이 어긋나지 않습니다.

## 쓰시기 전에

**Nerd Fonts v2를 쓰시던 설정이라면 아이콘이 두부(□)로 나올 수
있습니다.** v3에서 아이콘 다수가 다른 자리로 옮겨갔습니다. starship, eza,
lsd, nvim-web-devicons 같은 도구를 **Nerd Fonts v3를 지원하는 판으로 같이
올리시면** 해결됩니다.

**Pomicons는 넣지 않았습니다.** 상업적 이용이 제한되는 라이선스입니다.

## 어느 것을 받을까

네 가족 중 가장 많이 담은 판이라 파일이 큽니다.

- 한자가 필요 없으시면 → **Monoplex KR Nerd Font**
- 아이콘이 필요 없으시면 → **Monoplex CJK**
- 둘 다 필요 없으시면 → **Monoplex KR**

넷 다 줄 간격과 글자 폭이 같아서 섞어 쓰셔도 줄이 맞습니다.

## 설치

압축을 풀면 ttf 파일이 나옵니다. 쓰시는 운영체제의 방법대로 설치하시면
됩니다.
