# Monoplex CJK 1.0.0

첫 공개입니다.

**Monoplex KR**에 한자와 가나를 더한 프로그래밍 글꼴입니다. 한글·한자·
가나가 라틴의 정확히 두 배 폭이라, 넷을 한 줄에 섞어 써도 칸이 어긋나지
않습니다.

8종 굵기(Thin · ExtraLight · Light · Regular · Text · Medium · SemiBold ·
Bold)와 각각의 이탤릭이 들어 있습니다.

## Monoplex KR과 무엇이 다른가

Monoplex KR에는 한자가 한 글자도 없습니다. 그래서 한국어 문서를 보다가
`漢字`가 나오면 **그 글자만 시스템 글꼴로 넘어가면서 칸이 어긋납니다.**
표가 틀어지고 커서 위치가 튑니다.

이 글꼴이 그 자리를 채웁니다.

- **KS X 1001의 한자 4,888자를 빠짐없이** 담았습니다
- 히라가나·가타카나·반각 가타카나가 있어 일본어도 그대로 나옵니다
- 한자는 한국에서 쓰는 자형에 맞춰 골랐습니다. 이체자가 있을 때는
  중국·대만 쪽보다 일본 쪽 자형이 한국 자형에 가깝습니다

한자를 쓸 일이 없다면 Monoplex KR이 가볍고 충분합니다.

## 섞어 쓸 때를 위해 손본 것

**한자와 가나의 높이를 한글에 맞췄습니다.** 원래 한자는 한글보다 조금
위에, 가나는 그보다 더 위에 놓여 있어서, 섞어 쓰면 한글만 내려앉아
보였습니다. 셋의 윗선이 한 줄에 서도록 내렸습니다. 글자 모양과 획 굵기는
건드리지 않았습니다.

**이탤릭은 라틴과 한글만 기울입니다.** 한자와 가나는 이탤릭 굵기에서도
곧게 섭니다. 한자와 가나는 전통적으로 이탤릭이 없어 기울이면 어색합니다.

## 다른 가족과 같이 써도 됩니다

줄 간격과 글자 폭이 Monoplex KR과 같습니다. 편집기마다 다른 글꼴을 쓰셔도
줄이 맞습니다.

터미널 프롬프트나 파일 아이콘에 Powerline·Nerd Fonts 글리프를 쓰신다면
**Monoplex CJK Nerd Font**를 받으세요.

됩니다.
